# RhythmAI

شريك حياة ذكي: يتعلم روتينك، يخطط معك (لا يخطط لك)، يتابعك بلطف، ويبحث لك بعمق — كل هذا محليًا وباحترام كامل لخصوصيتك.

هذا تطبيق مستقل بالكامل عن تطبيق `New folder/apps/web` الموجود في هذا المستودع، ولا يشترك معه في أي كود أو تبعيات.

## المبادئ

- **لا يخطط لك، بل معك**: كل خطة أسبوعية تُقترح تحتاج موافقتك الصريحة قبل أن تُحفظ.
- **خصوصية كاملة**: ملفك الشخصي وخطتك وسجل بحثك يُحفظون فقط في `localStorage` الخاص بمتصفحك. لا يوجد خادم خلفي لهذا التطبيق.
- **لا نصائح طبية**: RhythmAI لا يشخّص ولا يصف علاجًا أبدًا. أي سؤال صحي جدي يُقابَل بتنبيه واضح لمراجعة طبيب.

## التشغيل محليًا

```bash
cd rhythmai
npm install
npm run dev
```

يفتح على `http://localhost:3001`.

## الذكاء الاصطناعي

يستخدم التطبيق Anthropic API مباشرة من المتصفح (بدون خادم وسيط). لتفعيله:

1. افتح **الإعدادات** داخل التطبيق.
2. الصق مفتاح Anthropic API الخاص بك.

يُرسل المفتاح فقط إلى `api.anthropic.com` مباشرة من متصفحك، ويُحفظ فقط في `localStorage` المحلي. بدون مفتاح، يعمل التطبيق باقتراحات عامة مبسطة (fallback) حتى لا يتوقف عن العمل.

> ملاحظة: الاستدعاء المباشر من المتصفح لواجهة Anthropic مخصص للنماذج الأولية (prototyping). لإصدار إنتاجي حقيقي يُنصح بإضافة خادم وسيط بسيط يخفي المفتاح عن العميل.

## البنية

```
src/
  lib/
    storage.js   # طبقة الحفظ المحلي (localStorage)
    ai.js        # نداءات Claude + خطط احتياطية بدون مفتاح
    safety.js    # كشف الأسئلة الصحية + قواعد السلامة
  pages/
    OnboardingPage.jsx   # التعرف على المستخدم لأول مرة
    DashboardPage.jsx    # مهام اليوم
    PlanPage.jsx          # اقتراح/تعديل/اعتماد الخطة الأسبوعية
    ResearchPage.jsx      # البحث العميق مع تنبيهات السلامة
    SettingsPage.jsx      # مفتاح API، الملف الشخصي، تصدير/حذف البيانات
```

## القيود الحالية (MVP)

- لا توجد إشعارات push حقيقية خارج المتصفح — فقط تذكيرات داخل الواجهة.
- لا يوجد تزامن بين الأجهزة (البيانات محلية فقط بتصميم مقصود).
- البحث العميق يعتمد على نموذج Claude نفسه دون أدوات بحث ويب خارجية بعد.
